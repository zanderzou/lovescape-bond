# Japanese edition — private editorial drafts

These files are original Japanese working copy, **not public pages**. The normal production build has no `/ja/` routes; its `draftJa` collection is empty and its Pages output remains `dist/client`. Run `npm run build:private:ja` to render the twelve pages as a local **noindex** preview in the separate `dist/private-ja-preview` directory, then run `npm run test:private:ja`. Do not deploy that preview directory or enable Japanese routes in production until the per-locale release gate, Japanese editorial review, responsive/consent QA and scheduled slot have passed. Refer to [SOURCES.md](SOURCES.md) for source conflicts and editorial decisions. Recheck changing provider facts immediately before release.

Draft inventory: `home.md`, `blog.md`, five `lovescape-vs-*.md` articles, and About, Contact, Editorial Policy, Privacy and Terms. All 12 copy drafts are present and locally rendered in the private preview as of 2026-09-30. The preview's static audit passed 12/12 pages and 296 internal links. `npm run test:private:ja:visual` checked all 12 pages at true 1440px, 390px and 320px browser viewports (36/36, no horizontal overflow), with homepage and comparison-article screenshots plus an opened mobile-menu check. `npm run test:private:ja:consent` passed no pre-consent Google request, decline, opt-in and GPC override using an isolated browser mapped to the real hostname; Google endpoints were blocked during the test. These are local technical checks, not independent native-language or legal review. No public release slot has been used and `/ja/` is not live. No `hreflang=ja`, production sitemap entry or English-site language-switch link may point here until public acceptance.
