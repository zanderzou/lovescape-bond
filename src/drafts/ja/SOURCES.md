## Provider facts and current conflict

1. Lovescape says it is for fictional adult characters, and disallows real-person photo uploads, deepfakes, minors and non-consensual scenarios. It names Warmtech Ltd as operator. [Provider statement](https://lovescape.com/blog/what-is-lovescape-how-it-works-what-it-isnt-and-what-it-will-never-allow/).
2. Official Chips help says purchased Chips are tied to an account, non-refundable, do not expire, and may be purchased only by subscribed users. Chip costs for generation are shown before the action. Promotions may differ. [Chips help](https://help.lovescape.com/hc/en-us/articles/30828415556881-Lovescape-Chips-What-They-Are-How-They-Work-and-How-to-Use-Them).
3. An older [Premium help article](https://help.lovescape.com/hc/en-us/articles/31060479234705-Lovescape-Premium-Membership) calls Premium the highest plan, while a later [feature release](https://lovescape.com/blog/features-friday-32-image-batches-for-ultra-cleaner-galleries/) describes Ultra. The release also contains an unresolved placeholder for batch Chip cost. **Do not declare a universal highest tier or infer batch pricing.** Check the live purchase and feature screens.
4. The provider [acknowledges imperfect memory and image consistency](https://help.lovescape.com/hc/en-us/articles/26467822971025-Lovescape-AI-Limitations-Challenges-Consistency-and-Privacy-Explained) and describes characters as private by default unless shared. Attribute privacy and security statements to the provider; they are not this publication's independent security audit.
