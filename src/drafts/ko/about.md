# 사이트 소개

`lovescape.bond`는 Lovescape의 공개 제품 자료와 대안을 살펴보는 독립 정보 사이트입니다. 공식 제품 운영사가 아니며, 계정, 결제 또는 캐릭터 생성 기능을 운영하지 않습니다.

## 우리가 설명하는 것

가상 성인 캐릭터의 설정, 대화의 연속성, 이미지와 영상의 연결, 사용 화폐와 구독 조건을 실제 선택에 필요한 질문으로 정리합니다. 장점을 나열하는 데서 끝내지 않고 재생성, 기억의 모순, 장기 결제와 개인정보 확인 같은 제약도 설명합니다.

## 제공하지 않는 것

실존 인물의 모방, 사진 업로드, 비밀 대화 수집이나 전문 상담을 제공하지 않습니다. 이미지는 편집용이며 서비스가 보증한 성과나 이용자의 실제 대화 기록이 아닙니다.

이 한국어판은 로컬 검증용 초안입니다. 게시 전 공식 자료와 기능 변경을 다시 확인해야 합니다. [편집 원칙](/ko/editorial-policy/)과 [개인정보 안내](/ko/privacy/)에서 출처와 측정 방식을 확인할 수 있습니다.
