# 개인정보 안내

이 문서는 `lovescape.bond` 정보 사이트에 관한 설명입니다. `lovescape.com`에 입력한 대화나 계정 정보는 해당 제품 운영사의 정책이 적용됩니다.

## 수집하지 않는 정보

채팅, 로그인, 결제, 음성 녹음, 사진 업로드 또는 프롬프트 저장 기능이 없습니다. 대화 기록과 비밀번호를 요구하지 않습니다. 예정된 `support@lovescape.bond` 주소도 아직 메일을 받도록 설정되지 않았습니다.

## 페이지 전송

호스팅과 보안 제공자는 페이지 전송 및 악용 방지를 위해 IP 주소, 브라우저, 요청 URL, 시간과 기술 신호를 처리할 수 있습니다. 이것이 다른 AI 서비스에서 나눈 개인 대화를 편집팀이 받는다는 뜻은 아닙니다.

## 선택적 Google Analytics

명시적으로 허용하기 전에는 측정 코드를 시작하지 않습니다. 페이지 하단 설정에서 거절하거나 동의를 철회할 수 있습니다. Global Privacy Control과 Do Not Track 신호를 존중합니다. 선택은 브라우저 로컬 저장소에 최대 180일 보관되며, 측정 쿠키의 설정 수명도 최대 180일이고 이용 중 갱신될 수 있습니다.

허용하면 페이지 조회, 스크롤, 외부 클릭, 기기와 유입 경로를 측정할 수 있습니다. Google signals와 광고 개인화는 사용하지 않습니다. 측정에 설정하는 페이지 URL에서 쿼리와 프래그먼트를 제거하며 개인 프롬프트를 보내지 않습니다. Google의 처리가 거주 국가 밖에서 이루어질 수 있으므로 [Google 개인정보처리방침](https://policies.google.com/privacy)과 [수신 거부 도구](https://tools.google.com/dlpage/gaoptout)를 함께 확인하세요.

동의 철회 시 측정을 중지하고 이 사이트에서 제거 가능한 분석 쿠키를 삭제합니다. 이미 Google이 처리한 데이터까지 삭제된다고 보장하지 않습니다. 로컬 검증에서는 요청을 가로채 실제 Analytics 속성에 테스트 방문을 전송하지 않습니다.

## 다른 사이트로 이동할 때

추천 링크에는 추천 코드가 포함될 수 있습니다. Playbox나 제품 사이트를 열면 해당 사이트의 정책이 적용됩니다. 초안의 설명과 기술 설정이 바뀌면 실제 게시 전에 다시 맞춰야 합니다.
