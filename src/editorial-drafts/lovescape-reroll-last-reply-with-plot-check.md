Lovescape's Take Two release notes describe regenerating the latest character reply. Use the control when the last version makes an unwanted choice or inserts an incorrect fact. Decide what the scene needs before judging a new reply.

## Mark what actually changed

In a fictional adult road story, you have agreed that a repaired van stays at the garage until morning. The last reply starts the next drive that night. If the reroll control is available, look for a version that keeps the timing. If subsequent replies still disagree, put the agreed time in your next message as plainly as possible.

## Continue from the choice you accept

Keep the version that follows the shared decision and gives you a next action. If the first reply already fits the plot, you can improve style later without reopening it. The release note describes the reply you keep as the one that goes into the conversation history.
