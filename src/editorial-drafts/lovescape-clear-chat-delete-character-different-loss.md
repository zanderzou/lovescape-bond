Choose the action for the thing you intend to remove. Lovescape's character-profile help distinguishes Clear Chat, which removes the chat history with a character, from Delete Character, which permanently removes the character.

The help describes both as irreversible. Do not use either action as a casual way to inspect a menu or solve a minor wording problem.

## Separate the conversation from the character

A character has profile attributes and a role, while a conversation contains an unfolding exchange. Lovescape's character guide also identifies ongoing conversation context as a contributor to replies.

For an original adult story, you might want to keep a fictional architect while retiring an old room-design scene. That is a different aim from removing the architect character altogether.

## Review what you need before confirming

Read any dialogue or scene detail you still want to retain before selecting an irreversible action. If you make a separate personal note, keep it limited to content you are entitled to retain.

Such a note is not a product backup, an import file or a promise that the previous conversation can be restored. Do not delete history merely because a concise recap seems similar to a complete transcript.

The documented profile route is Characters, My Characters, then the selected character. The more-options menu contains the relevant management actions. Inspect the current labels and confirmation carefully because interfaces can change.

## Match the confirmation to the intended loss

If your aim is history removal while retaining the character, verify that the confirmation refers to Clear Chat rather than Delete Character. If it names the wrong action, cancel before proceeding.

A profile edit is another separate operation. Changing one personality attribute does not require deleting the entire character simply because its management options share a menu.

This guide performs no deletion and promises no recovery. If the account or character is missing unexpectedly, investigate that problem before attempting further destructive steps. The useful decision is to identify exactly what you want to remove and accept its documented consequence before confirming.
