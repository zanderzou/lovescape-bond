Choose one visual detail that the image must communicate. For a scene where an original fictional adult signals across a courtyard with a red fan, the requirement might be “the open red fan is visible above the chair.” A pleasant pose or outfit can be secondary.

Lovescape's own image guidance describes giving scene details for an existing fictional character. The check here works on the returned image and uses a text-only scene example.

One of the small samples includes a red fan. The clue is visible even when the portrait is reduced.

## Check the detail at the size you will use

Open the image at its planned viewing size. Find the fan without zooming in. If it is still easy to spot and the pose fits the scene, you already have the detail the next reader needs. If a hand or chair obscures it, describe where it should sit instead of rewriting the whole scene.

For example, keep the setting and outfit. Change “holds a fan” to “holds an open red fan above the right arm of the chair, against the pale wall.” This adds separation around the item and gives you the same criterion on the next pass.

## Stop when you can use the result

Compare the available images against the same requirement. If another request would add cost or time, use the displayed quote and your existing result to decide whether the missing detail warrants a new attempt.
